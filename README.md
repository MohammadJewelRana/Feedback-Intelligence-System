# 🚀 FedIQ – AI Powered Feedback Intelligence System

FedIQ is a full-stack AI powered feedback management system that automatically analyzes and routes user feedback using LLM intelligence.

The platform allows users to submit feedback while the system uses AI to extract category, priority, sentiment, and responsible team. Feedback can be searched, filtered, and managed through a modern dashboard interface.

This project demonstrates full-stack TypeScript development with LLM integration.

## ✨ Features

### 👤 User Features
- View all submitted feedback
- Create feedback through modal form
- Search feedback by name
- Filter feedback by category
- Filter feedback by priority
- Responsive modern dashboard UI
- Real-time feedback statistics
- Responsive UI (Mobile, Tablet, Desktop)

### AI Features
- The AI automatically analyzes the message and extracts:
   - Category
   - Priority
   - Sentiment


### ⚙️ Technical Features
- RESTful API endpoints
- Model relationship (Job → Applications)

- Clean folder structure
- Reusable components
- Environment-based configuration
